# 프로토타입 개발을 위해 필수적으로 갖추어야할 요소

## 기본 스탯
### 플래이어
``` java
//플래이어
int hp = 100;
int STR = 12;
int DEX = 10;
```
플래이어는 2가지 행동을 할 수 있다.
- 타격
```java
//플래이어의 타격
STR의 100%만큼 상대 hp를 감소시킨다.
선딜은 (1턴)이다.{주먹으로 떄렸다.}
쿨타임은 1턴이다.
```

- 수비
```java
//플래이어의 수비
DEX의 100%만큼 상대의 공격을 막는다.
선딜은 (1턴)이다.{방패로 막았다.}
쿨타임은 2턴이다.
```
  
### 고블린(프로토타입용 몬스터)
``` java
//고블린
int hp = 100;
int STR = 8;
int DEX = 6;
```

고블린은 3가지 행동을 할 수 있다.
```java
//고블린의 기본 문장
고블린은 찔렀다.

//고블린의 공격 패턴 1
고블린은 [단검으로] [빠르게] 찔렀다. 

//고블린의 공격 패턴 2
고블린은 [하늘로] [뛰어올라] [단검으로] [강하게] 찔렀다.

//고블린의 공격 패턴 3
고블린은 [빠르게] [단검으로] 찌르고 [또] [강하게] 찔렀다.

빠르게, 하늘로, 뛰어올라, 강하게 : 10%p

```
