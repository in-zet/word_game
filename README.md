# word_game

Godot 4.7 기반 2D 게임 프로젝트입니다.

## 요구 사항

- [Godot Engine 4.7 이상](https://godotengine.org/download) (Standard 또는 .NET 버전)

## 실행 방법

1. Godot 에디터를 실행합니다.
2. "Import" 버튼으로 이 폴더의 `project.godot` 파일을 선택합니다.
3. 프로젝트를 열고 F5(또는 재생 버튼)로 실행합니다.

## 폴더 구조

```
word_game/
├── project.godot      # 프로젝트 설정 파일
├── icon.svg           # 프로젝트 아이콘
├── scenes/
│   └── main.tscn      # 메인 씬
├── scripts/
│   └── main.gd        # 메인 씬 스크립트
└── assets/            # 스프라이트, 폰트, 사운드 등 리소스
```
